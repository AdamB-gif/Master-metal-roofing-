# 03 — Keyword Map

One page = one primary keyword. Two pages must never target the same primary keyword — that is keyword cannibalization and it splits ranking signals between pages that then both underperform.

## How to use this map

For each page: the **primary** keyword goes in the title tag, the H1, the first 100 words, and the URL. **Secondaries** go in H2s and body copy, worked in as natural sentences. **Semantic terms** are vocabulary Google expects to co-occur on a page about this topic — use them where they fit; do not force them.

Write for the homeowner first. If a sentence exists only to hold a keyword, delete it.

## The cross-link mesh (do not build these as pages)

These long-tail combinations should rank via internal linking, not dedicated URLs:

- metal roofing contractor Richlands VA → covered by Richlands page + link to metal roofing service page
- standing seam metal roof Bluefield VA → covered by standing seam page + Bluefield link
- board and batten siding Pounding Mill → covered by board & batten page + Pounding Mill link

Building all 12 services × 14 towns = 168 combination pages is the classic doorway-page mistake. It will get the site filtered or manually penalized. The mesh in `02-site-architecture.md` achieves the same coverage safely.
